# Licence requests ready for human dispatch

Deployment site for all requests: Brookhaven National Laboratory.

No permission is presumed by these drafts. The human sender must select the
licensing contact published by each site and add their own name and contact
details before sending.

## SignalP 6 and SignalP 3 HMM

Licensor site: https://services.healthtech.dtu.dk/services/SignalP-6.0/

Subject: Permission request for SignalP use in a plant-pathogen effector benchmark at Brookhaven National Laboratory

```text
To the SignalP licensing contact,

I am requesting permission for Brookhaven National Laboratory to use SignalP 6 and the SignalP 3 HMM in a research benchmark of plant-pathogen effector candidate ranking.

The intended use is to run the software on Brookhaven-controlled computing infrastructure as one fixed secretion channel in a blinded comparison of mechanical and agent-assisted ranking methods. We intend to record the exact software revision and configuration, evaluate outputs against the benchmark's precision-at-k measurement, and publish aggregate benchmark results. We will not redistribute the software, model files, or licensed databases unless you grant that right explicitly.

Please state whether this use is permitted, which licence applies, whether local installation or container execution is allowed at Brookhaven National Laboratory, whether multiple project researchers may use the installation, and what citation, acknowledgement, reporting, or redistribution conditions apply.

Sincerely,

Brookhaven National Laboratory
```
