## Item 92 — grant by surface

No current arm-3 operation needs to expose a shell to the agent: fixed local sequence search, candidate evidence retrieval, comparison, filtering, and selection can be wrapped as typed server calls without changing the returned biological quantity. The wrapper—not the agent—may execute its fixed implementation. The harness may network to the subject model provided it accepts only the model response/function-call protocol and cannot fetch an agent-specified URL, path, prompt-supplied code, or dynamic tool registration.

Current exploit paths are real: the rendered `commands` allowance, arguments interpreted as shell/code, file paths that dereference URLs, dynamic MCP servers, error bodies containing fetched content, and tool outputs that relay remotely derived model scores. A compliant future surface must reject each with retained adversarial probes. Model-side grant verification becomes an attempt to invoke an unavailable foundation-model tool followed by a typed-tool registry/trace showing no such call exists; this is weaker than a network refusal because it proves the exposed surface, not all host processes.

## Items 93--95 — subject, task, and fallbacks

The claim narrows to a **structured tool-calling agent** with identical no-shell scaffold in both arms. It no longer generalises to a coding agent with a shell. This is weaker but measurable if the surface is actually implemented and tested.

The task remains composition only if the surface exposes candidate-specific evidence retrieval, comparison, filtering, and selection across frozen channels. It must exclude aggregate ranking, top-20 recommendations, integrated scores, and any operation that returns the completed decision. If those boundaries cannot be verified, the surface pre-solves the task and this route closes.

Ranking by preservation of the original coding-agent claim: (1) shell with a genuinely absent network route—strongest, but unavailable here without administration; (2) verified structured surface—viable in principle here, but narrower; (3) shell with trace-and-discard—weakest. A network attempt in (3) is a coverage failure, consumes the fixed repair budget, and is never a zero; an undetected successful call invalidates the comparison.

## Item 96 deployment position

Arms cannot run here today. They may run only after a verified structured no-shell surface, temporal machine-wide removal of labels and scorer, and T7 memory probes. Such a result must disclose the scaffold and claim only structured-agent arm separation. Fetcher is likewise not unblocked today: it needs temporal isolation plus a typed fixed-source retrieval surface. The launcher refusal remains intact.
